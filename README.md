Project Overview
This is a Java console-based application that allows users to manage different geometric shapes such as Circle, Rectangle, Square, and Triangle. The user can add, view, delete shapes, and perform operations like calculating area and perimeter, translating, and scaling. The project demonstrates key object-oriented programming concepts: encapsulation, inheritance, abstraction, and polymorphism.
How to Run
1. Open the project in any Java IDE (e.g., IntelliJ IDEA, Eclipse).
2. Place all `.java` files in the same package or folder.
3. Run `Main.java`.
4. Follow the on-screen menu and enter numbers to interact.
Classes Used
`Shape`: Abstract base class for all shapes.
`Circle`, `Rectangle`, `Square`, `Triangle`: Shape subclasses.
`Coordinates`: Handles x and y positions.
`ShapeList`: Stores and manages the list of shapes.
`ShapeManagement`: Handles menu and user interaction.
`Main`: Program entry point.
